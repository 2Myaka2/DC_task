Тема ВКР: «Кластеризация сетей взаимодействия аминокислотных остатков для идентификации конформационных состояний транспортёра NaPi2b»
Смысл работы заключается в том, что каждый кадр траектории рассматривается как сеть контактов между аминокислотными остатками. По этим сетям необходимо выделить группы похожих кадров, то есть конформационные состояния, а затем описать, чем эти состояния различаются по топологии графа.


Цель и задачи ВКР
Цель ВКР — выделить конформационные состояния транспортёра NaPi2b на основе кластеризации покадровых сетей контактов аминокислотных остатков и охарактеризовать эти состояния с помощью базовых методов топологического анализа графов.
Задачи:
1.	Разобрать структуру набора данных, сформированного на этапе Phase3A.
2.	Подготовить покадровые сети контактов остатков для анализа.
3.	Рассчитать компактный набор топологических признаков для каждого кадра.
4.	Выполнить кластеризацию кадров и определить число устойчивых состояний.
5.	Построить усреднённые сети выделенных состояний.
6.	Описать выделенные состояния по глобальным метрикам графа, центральностям и региональной вовлечённости остатков.
